Capture this into the company brain: **$ARGUMENTS**

Use the `remember` tool. Before writing:

- Give it a short durable title.
- Choose a `kind` that fits: `note`, `decision`, `meeting`, `research`,
  `person`, `project`.
- Set `confidence` honestly — `stated` when the user asserted it, `observed`
  when you saw it in a source, `inferred` when you concluded it, `draft` when
  it is provisional.
- Add `facts` only for things the user actually stated, using
  `predicate:: value` or `subject|predicate:: value`. Never invent typed facts.

If the information is ambiguous about who or what it concerns, ask one
clarifying question before writing rather than guessing.

Afterwards report the file path it created and the entities it linked to.
